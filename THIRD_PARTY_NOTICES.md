# Third-party notices

## Fakeflix

The interaction model for FreeTuve's prebuilt practice catalogue was informed by
[Fakeflix](https://github.com/Th3Wall/Fakeflix), created by Davide Mandelli and
released under the MIT License.

FreeTuve does not embed Fakeflix's Firebase/TMDB application, Netflix assets,
Netflix media, Netflix audio, or Netflix branding. The catalogue implementation
in FreeTuve is rewritten for its existing vanilla JavaScript frontend and uses
original practice content plus browser speech synthesis.

## Clone Wars

[Clone Wars](https://github.com/GorvGoyl/Clone-Wars) was used as the discovery
index that led to Fakeflix and other open-source streaming-interface examples.
